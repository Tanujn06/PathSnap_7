# PathSnap Data & API Contract

Agreed at 10:00, 18 Nov 2026. Every teammate builds against this exact
contract so branches merge without rewriting each other's assumptions.

## Conventions

- Python 3.11+, seeds are 42 everywhere, CV is GroupKFold(5) grouped by
  `trip_id`.
- Projection: local metric projection per trip,
  `x = (lon - lon0) * cos(lat0) * 111320`,
  `y = (lat - lat0) * 110574` (metres), with `lon0, lat0` at the trip
  centroid.
- Tables are parquet files in `data_cache/` (gitignored, regenerated by
  scripts). `{split}` is `train` or `student_test`.
- The API reads trip folders from the environment variable `EVAL_DATA_DIR`.

## Tables

| File | Columns | Written by | Read by |
| --- | --- | --- | --- |
| `cands_{split}` | `trip_id, obs_idx, arc_id, dist_m, along_frac, cand_rank` | DATA-02 | FEAT-01, HMM-01 |
| `labels_{split}` | `trip_id, obs_idx, ref_arc, ref_dist_m` | DATA-04 | FEAT-01, EVAL-01 |
| `features_{split}` | `trip_id, obs_idx, arc_id, label`, then the feature columns in the fixed order stored in `configs/feature_columns.json` | FEAT-01 | TRAIN-01 to TRAIN-05 |
| `probs_<model>_{split}` | `trip_id, obs_idx, arc_id, p_match` | TRAIN-03, TRAIN-05 | HMM-02, PIPE-01 |

## API reference

| Method | Path | Purpose | Backed by |
| --- | --- | --- | --- |
| GET | `/health` | Returns `{status: ok}` | API-01 |
| GET | `/trips` | Lists the trip ids found in `EVAL_DATA_DIR` (the 10 evaluator trips at the demo) | API-01 |
| POST | `/predict` | Body `{trip_id}`. Runs the full pipeline. Response: `trip_id, n_obs, gps` `[[lat,lon],..]`, `predicted_arcs`, `predicted_path` `[[lat,lon],..]`, `metrics` `{top1, macro_f1, route_continuity, sequence_f1}`, `latency_ms`. The reference route is NOT in the response. | API-01 (stub), API-02 (real) |
